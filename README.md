# MeetMind

MeetMind is an AI-powered meeting workspace for recording audio, generating automated summaries, extracting key decisions, and tracking action items.

## Features

- **Audio Recording**: Record meetings directly in the browser with real-time waveform visualization.
- **Automated Transcription**: Convert spoken dialogue into structured transcripts with speaker attribution.
- **AI Synthesis**: Generate concise overviews, key decisions, attendee lists, and action items.
- **Action Item Management**: Track tasks with priority tags, assignees, deadlines, and completion status.
- **Shareable Summaries**: Generate public share links for team visibility.

## Tech Stack

- **Framework**: Next.js 16 (App Router, React 19, TypeScript)
- **Styling**: Vanilla CSS
- **Database & Storage**: PostgreSQL (Supabase) / Local Storage Fallback

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
